## ✨ Key Features

- 📊 **Dynamic Dashboard:** Live tracking of daily mood, consistency streaks, and composite productivity metrics.
- ✅ **Smart Task Engine:** Intuitive task manager with reordering, emoji categorization, skip tracking, and celebratory animations.
- 📓 **AI Reflection Journal:** Daily guided prompts with rich text reflection and AI coaching summaries.
- 📈 **Mood Heatmaps & ML Predictions:** Visual trend tracking using TensorFlow.js to predict burnout patterns.
- 🔒 **Privacy & Local-First:** All user data is encrypted and saved directly in browser `localStorage` for complete data privacy.
- 📱 **Progressive Web App (PWA):** Offline service-worker caching, installable on mobile and desktop.

## 🚀 Quickstart

### 1. Clone & Install
```bash
git clone https://github.com/jannu15006-ship-it/Mr-D-productivity-os.git
cd Mr-D-productivity-os

npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
npm run preview
```
